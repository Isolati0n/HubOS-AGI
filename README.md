# HubOS-AGI

**AGI premise, not buildable today.** This repository is a thought experiment, not a build.

It holds design documents for the endgame of the owner's Hub OS cluster, written as if an AGI could produce any software in seconds. Hardware, vendor firmware and physics stay fixed. Nothing here is a decision for the real build.

The real build is a different repository: https://github.com/Isolati0n/HubOS. Its `HUB-OS.md` on `main` is the source of truth for the real build.

## What is here

- `docs/vision/` : one document per machine, in this order: hub, NAS and backup NAS, the three one-app nodes (browser, editor, music), VM host, gaming box.
- `docs/vision/hub.md` : the hub's target list (approved by the owner on 2026-10-14) and its design, which is being written part by part.
- `CLAUDE.md` : the rules every bot session follows in this repository.

## How to read the documents

Every claim carries one label:

- TESTED : a command was run and its output was seen.
- SOURCE : read in a named link or file, with the date.
- BELIEVED : not checked.
- UNKNOWN : not established.

Almost every number in these documents is a target or a calculated estimate, not a measurement.

## Where the rules live

The track's source of truth is the file `HUB-OS-AGI.md` in the owner's claude.ai project "Hub OS - AGI". `CLAUDE.md` here is a copy of the parts the bot needs. If the two disagree, the project file wins.
